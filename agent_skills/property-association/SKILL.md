---
name: property-association
description: Investigate Vexcel and CoStar evidence for the selected site without conflating nearby properties or exposing raw records.
---

Call find_parcel_and_buildings, detect_site_features and read_costar_property. These tools resolve and measure records locally. Identify which mapped surfaces, building coverage, property use, parking or loading facts change the decision. Distinguish an unavailable source from no matching records. A nearby detector is a candidate, not a measured footprint or proof of land control. Never infer ownership from proximity or choose a different property. Use search_aerial_imagery only to clarify an ambiguity after a source attempt; tiles are not object outlines. Return concise cited findings and unresolved checks. The application saves your validated report at /project/reports/site-evidence.json. Keep exploratory notes under /project/notes/site-evidence/.
