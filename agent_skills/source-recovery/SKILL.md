---
name: source-recovery
description: Diagnose a missing or failed source and select a bounded recovery action while preserving the selected site.
---

Classify a source gap as unavailable, no match, ambiguous association or unsupported inference. Transient transport errors receive at most one application-controlled retry. Never repeat unchanged failed requests. For ambiguous imagery use the imagery-search tool at most once; for missing local context query the supported neighborhood source. Neither can substitute a neighboring property or verified traffic demand. Keep completed evidence and partial specialist reports. If no supported recovery resolves the blocker, report the specific gap and ask the smallest actionable question. Do not invent facts, silently change the site, bypass access controls or claim a failed evaluation passed.
